Windows fájlszerver komplex feladat - GUI, CMD és PowerShell

Komplett, összehasonlító megoldás helyi felhasználókkal és csoporttal a FS Windows fájlszerveren.

Cél: az m1 és m2 felhasználó a munkas csoport tagjaként olvassa a közös feladatokat, saját mappájába írjon, egymás mappájához ne férjen hozzá. A boss feltölt, ellenőriz és archivál.

1. Feltételezések és mappaszerkezet

  • Szerver: FS
  • Fizikai út: D:\Munka
  • Megosztás: \FS\munka
  • Helyi fiókok: m1, m2, boss
  • Helyi csoport: munkas
D:\Munka
├── Kozos        boss ide tölti a feladatokat
├── Sajat
│   ├── m1       csak m1 és boss
│   └── m2       csak m2 és boss
└── Archiv
    ├── m1
    └── m2

3. GUI-megoldás

3.1 Felhasználók és csoport

  1. Számítógép-kezelés → Helyi felhasználók és csoportok → Felhasználók.
  2. Új felhasználóként hozza létre: m1, m2, boss.
  3. A Csoportok alatt hozzon létre munkas nevű csoportot.
  4. Adja hozzá az m1 és m2 fiókot.

3.2 Mappák

A Fájlkezelőben hozza létre a fenti teljes mappaszerkezetet.

3.3 Biztonsági jogosultságok

  1. Mappa jobb gomb → Tulajdonságok → Biztonság → Speciális.
  2. A védett mappákon válassza az Öröklés letiltása lehetőséget.
  3. A saját mappák és az archívum esetén távolítsa el az örökölt jogosultságokat.
  4. Adja hozzá a jogosultsági terv táblázatában szereplő fiókokat.
  5. A SYSTEM és az Administrators minden védett mappán kapjon Teljes hozzáférést.

3.4 Megosztás

  1. D:\Munka jobb gomb → Tulajdonságok → Megosztás → Speciális megosztás.
  2. Jelölje be a Mappa megosztása opciót, név: munka.
  3. Engedélyeknél törölje az Everyone bejegyzést.
  4. munkas: Módosítás; boss és Administrators: Teljes hozzáférés.

5. Teljes PowerShell-megoldás

A szkript Windows PowerShell 5.1 alatt, rendszergazdai jogosultsággal futtatható. Nem tárol nyílt szövegű jelszót.

# Futtatás rendszergazdai Windows PowerShell 5.1-ben
$Root = "D:\Munka"
$Computer = $env:COMPUTERNAME
$BossAccount = "$Computer\boss"
$WorkerGroup = "$Computer\munkas"
$M1Account = "$Computer\m1"
$M2Account = "$Computer\m2"

# Jelszavak biztonságos bekérése
$M1Password = Read-Host "Az m1 jelszava" -AsSecureString
$M2Password = Read-Host "Az m2 jelszava" -AsSecureString
$BossPassword = Read-Host "A boss jelszava" -AsSecureString

# Helyi felhasználók
if (-not (Get-LocalUser m1 -ErrorAction SilentlyContinue)) {
  New-LocalUser -Name m1 -Password $M1Password -FullName "Munkatárs 1"
}
if (-not (Get-LocalUser m2 -ErrorAction SilentlyContinue)) {
  New-LocalUser -Name m2 -Password $M2Password -FullName "Munkatárs 2"
}
if (-not (Get-LocalUser boss -ErrorAction SilentlyContinue)) {
  New-LocalUser -Name boss -Password $BossPassword -FullName "Ellenőrző vezető"
}

# Csoport és tagság
if (-not (Get-LocalGroup munkas -ErrorAction SilentlyContinue)) {
  New-LocalGroup -Name munkas -Description "A munka megosztás dolgozói"
}
$members = (Get-LocalGroupMember munkas -ErrorAction SilentlyContinue).Name
if ($members -notcontains "$Computer\m1") { Add-LocalGroupMember munkas m1 }
if ($members -notcontains "$Computer\m2") { Add-LocalGroupMember munkas m2 }

# Mappák
$Folders = @(
  $Root, "$Root\Kozos", "$Root\Sajat", "$Root\Sajat\m1", "$Root\Sajat\m2",
  "$Root\Archiv", "$Root\Archiv\m1", "$Root\Archiv\m2"
)
$Folders | ForEach-Object { New-Item -Path $_ -ItemType Directory -Force | Out-Null }

function Set-FolderPermissions {
  param([string]$Path, [array]$Permissions)
  $Acl = Get-Acl -LiteralPath $Path
  $Acl.SetAccessRuleProtection($true, $false)
  foreach ($Rule in @($Acl.Access)) { [void]$Acl.RemoveAccessRuleAll($Rule) }
  foreach ($Permission in $Permissions) {
    $Rule = [System.Security.AccessControl.FileSystemAccessRule]::new(
      $Permission.Identity, $Permission.Rights,
      "ContainerInherit,ObjectInherit", "None", "Allow")
    [void]$Acl.AddAccessRule($Rule)
  }
  Set-Acl -LiteralPath $Path -AclObject $Acl
}

$adminRules = @(
  @{Identity="SYSTEM"; Rights="FullControl"},
  @{Identity="BUILTIN\Administrators"; Rights="FullControl"},
  @{Identity=$BossAccount; Rights="FullControl"}
)

Set-FolderPermissions $Root ($adminRules + @{Identity=$WorkerGroup; Rights="ReadAndExecute"})
Set-FolderPermissions "$Root\Kozos" ($adminRules + @{Identity=$WorkerGroup; Rights="ReadAndExecute"})
Set-FolderPermissions "$Root\Sajat" ($adminRules + @{Identity=$WorkerGroup; Rights="ReadAndExecute"})
Set-FolderPermissions "$Root\Sajat\m1" ($adminRules + @{Identity=$M1Account; Rights="Modify"})
Set-FolderPermissions "$Root\Sajat\m2" ($adminRules + @{Identity=$M2Account; Rights="Modify"})
Set-FolderPermissions "$Root\Archiv" $adminRules
Set-FolderPermissions "$Root\Archiv\m1" $adminRules
Set-FolderPermissions "$Root\Archiv\m2" $adminRules

# SMB-megosztás
if (Get-SmbShare -Name munka -ErrorAction SilentlyContinue) {
  Remove-SmbShare -Name munka -Force
}
New-SmbShare -Name munka -Path $Root `
  -Description "Közös munkaterület és személyes munkamappák" `
  -ChangeAccess $WorkerGroup `
  -FullAccess $BossAccount,"BUILTIN\Administrators" `
  -FolderEnumerationMode AccessBased

Write-Host "Elkészült: \\$Computer\munka" -ForegroundColor Green

6. Napi munkafolyamat és archiválás

  1. boss: feltölti a feladatot a \FS\munka\Kozos mappába.
  2. m1: a fájlt a \FS\munka\Sajat\m1 helyre menti.
  3. m2: a fájlt a \FS\munka\Sajat\m2 helyre menti.
  4. boss: ellenőrzés után az Archiv\m1 vagy Archiv\m2 mappába helyezi.

Archiválás CMD-ből

robocopy "D:\Munka\Sajat\m1" "D:\Munka\Archiv\m1" /E /MOVE
robocopy "D:\Munka\Sajat\m2" "D:\Munka\Archiv\m2" /E /MOVE

Dátum szerinti archiválás PowerShellből

$Date = Get-Date -Format "yyyy-MM-dd"
foreach ($User in 'm1','m2') {
  $Source = "D:\Munka\Sajat\$User"
  $Destination = "D:\Munka\Archiv\$User\$Date"
  New-Item $Destination -ItemType Directory -Force | Out-Null
  Copy-Item "$Source\*" $Destination -Recurse -Force
}
# Ellenőrzés után a forrásfájlok törölhetők.

7. Ellenőrzési terv

Másik felhasználó tesztje előtt bontsa a korábbi kapcsolatokat: net use * /delete.

m1 teszt

net use Z: \\FS\munka /user:FS\m1 *
dir Z:\Kozos
dir Z:\Sajat\m1
dir Z:\Sajat\m2
dir Z:\Archiv
  • ✓ Közös fájlok olvashatók, de nem módosíthatók.
  • ✓ Saját m1 mappában létrehozás, módosítás és törlés működik.
  • ✓ m2 és Archiv nem érhető el.

m2 teszt

Ugyanez /user:FS\m2 hitelesítéssel; csak a Sajat\m2 legyen írható.

boss teszt

A boss írjon a Közös mappába, nyissa meg mindkét saját mappát, majd másoljon az Archiv mappába.

9. Hibakeresés

  • Hozzáférés megtagadva: ellenőrizze külön a megosztási és az NTFS-jogokat.
  • Másik fiókkal sem kér jelszót: net use * /delete, majd újracsatlakozás.
  • A munkás látja a másik mappát: ellenőrizze az öröklést, valamint az Authenticated Users és Users bejegyzéseket.
  • Helyi csoportnév nyelvi hiba: CMD-ben az Administrators SID-je S-1-5-32-544; PowerShellben a beépített csoport feloldását ellenőrizni kell lokalizált rendszeren.
